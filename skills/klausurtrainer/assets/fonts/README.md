# Schriften

Archivo 2.001 (Omnibus-Type) und JetBrains Mono 2.211 (JetBrains), beide unter
der SIL Open Font License 1.1 (`OFL_Archivo.txt`, `OFL_JetBrainsMono.txt`).

Die Dateien sind statische Schnitte der variablen Fonts aus google/fonts und
glyphengleich mit den Schriften im Design System TUDa UI (dort als WOFF2-Subsets).
Sie enthalten Lateinisch mit Erweiterungen, Satzzeichen, Währungs-, Pfeil- und
Mathematikzeichen.

| Datei | Schnitt | Einsatz |
|---|---|---|
| `Archivo-Regular.ttf` | 400 | Fließtext, Tabellen, Kopf- und Fußzeile |
| `Archivo-SemiBold.ttf` | 600 | Beschriftungen, Tabellenköpfe, Dachzeilen, Kennzahlen |
| `Archivo-Bold.ttf` | 700 | Aufgabentitel, Hervorhebungen, punktegebende Antworten |
| `Archivo-ExtraBold.ttf` | 800 | großer Titel auf dem Deckblatt |
| `Archivo-Italic.ttf`, `Archivo-BoldItalic.ttf` | 400, 700 kursiv | `<i>` im Text |
| `JetBrainsMono-Medium.ttf` | 500 | Kennungen: Modulkürzel, Quellanker, Materialeinheiten |
